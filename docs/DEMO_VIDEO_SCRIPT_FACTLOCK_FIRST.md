# Demo Video Script — FactLock First (3 Minutes Max)

This script is designed to make **FactLock** the hero feature so MuseForge does not look like a generic portfolio builder.

## Core message

> MuseForge is not just an AI portfolio generator. It is a **Fact-Locked AI portfolio builder** that helps creators write faster **without letting AI invent fake achievements**.

---

## Recommended flow

### 0:00–0:20 — Problem
- Say: “Creators often have real work but poor presentation. Generic AI can improve writing, but it can also invent tools, metrics, clients, and achievements.”
- Show the landing page briefly.

### 0:20–0:45 — Input
- Open a creator form.
- Enter short, imperfect project details.
- Mention that input can be in **any language**.
- Show the language selector.

### 0:45–1:35 — Make FactLock the hero
- Generate the portfolio.
- **Immediately show the FactLock panel.**
- Explain these 4 things clearly:
  1. original description
  2. AI-enhanced description
  3. preserved facts
  4. unsupported new facts detected
- Show one example where the user can:
  - accept enhanced
  - edit enhanced
  - keep original
- Say: “This is the key innovation. MuseForge keeps AI useful, but reviewable and grounded.”

### 1:35–2:00 — Show the final portfolio
- Scroll through the generated portfolio preview.
- Point out that output can be generated in the selected language.

### 2:00–2:20 — Shareable URL
- Create the public portfolio link.
- Open the public portfolio page.
- Mention persistent production storage support.

### 2:20–2:35 — IBM Bob proof
- Show 2–3 screenshots from `docs/ibm-bob-evidence/`.
- Say: “IBM Bob was our primary development tool for planning, debugging, and deployment preparation.”

### 2:35–3:00 — Close strong
- Say: “MuseForge helps creators build portfolios faster, in multiple languages, while FactLock reduces the risk of unsupported AI claims.”
- End on the public portfolio page or FactLock panel.

---

## Ruthless mentor note

If the demo spends more time on generic form-filling than on FactLock, the project will look ordinary. The **judges must remember FactLock first**, and multilingual/shareable links second.
