# MuseForge User Testing Plan

This document is for collecting real evidence before the AI Builders Challenge submission. Do not fill this with fake numbers.

## Goal

Measure whether MuseForge helps creators build authentic portfolios faster without AI inventing unsupported facts.

## Test Participants

Target at least 10 participants:

- 3 artists/designers
- 2 writers
- 2 musicians/content creators
- 3 students/job seekers

## Test Script

Ask each participant to:

1. Open MuseForge.
2. Choose the creator type closest to their work.
3. Fill the form with real details.
4. Add at least one project.
5. Choose the output language.
6. Generate the portfolio.
7. Review the FactLock panel.
8. Accept, edit, or keep original descriptions.
9. Create a shareable portfolio link.
10. Rate the experience.

## Metrics to Record

- participant type
- input language
- output language
- time to first generated portfolio
- number of project descriptions enhanced
- number accepted
- number edited
- number rejected / original kept
- unsupported facts detected by user
- satisfaction score out of 5
- main feedback quote

## Honest Reporting Rule

If a user finds a fake or unsupported fact, include it. It is better to show that FactLock exposed a problem than to pretend the AI was perfect.
